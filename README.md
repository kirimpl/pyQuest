## Краткое описание

**PyQuest Code Adventure** — обучающая игра для изучения Python, в которой игрок пишет код для управления героем на карте. Каждый уровень представлен как программируемый сектор: на поле расположены стены, кристаллы данных, ключи, шлюзы, терминалы, баги и выходной портал. Чтобы пройти сектор, игрок составляет программу, нажимает `RUN`, после чего герой выполняет команды пошагово.

Основная идея проекта — связать изучение Python с игровым действием. Пользователь не просто читает материал, а применяет конструкции языка для решения задач на карте: задаёт переменные, использует списки маршрутов, условия, циклы, функции, словари, обработку ошибок, загрузку данных, API-запросы, SQL-запросы и другие темы курса.

Игра использует безопасный учебный симулятор кода. Проект не выполняет настоящий Python-код как внешний интерпретатор, а обрабатывает ограниченный набор команд и конструкций, необходимых для прохождения уровней. Такой подход сохраняет контроль над логикой игры и исключает запуск произвольного кода.

## Игровой процесс

Основной цикл прохождения:

```text
Главное меню -> Карта кампании -> Сектор -> Код -> RUN -> Симуляция -> Результат -> Следующий сектор
```

Игрок выбирает открытый сектор на карте кампании. После загрузки сектора отображается карта и редактор кода. Пользователь пишет программу, использует команды героя и конструкции Python, затем запускает код. Симулятор выполняет действия по порядку и показывает, что произошло на карте.

Сектор засчитывается только тогда, когда выполнены все условия:

- герой дошёл до выхода;
- собраны требуемые кристаллы и ключи;
- открыты нужные шлюзы;
- активированы терминалы;
- устранены баги;
- использована тематическая конструкция уровня, если она обязательна.

Например, сектор JSON требует использования `json.load(...)`, сектор API требует `api.get(...)`, а сектор SQLite требует SQL-запрос и `db.query(...)`.

## Команды героя

Основные команды:

```python
hero.move_right()
hero.move_left()
hero.move_up()
hero.move_down()
hero.move("right")
hero.move("left")
hero.move("up")
hero.move("down")
hero.collect()
hero.attack()
hero.open_gate()
hero.activate()
hero.scan()
hero.status()
hero.say("текст")
hero.wait()
```

Проверки для условий:

```python
hero.can_move("right")
hero.near("gem")
hero.near("key")
hero.near("enemy")
hero.near("gate")
hero.near("terminal")
hero.has_key()
hero.has_item("key")
hero.at_exit()
hero.sees_enemy()
```

Пример:

```python
for i in range(3):
    hero.move_right()

if hero.near("gem"):
    hero.collect()

if hero.sees_enemy():
    hero.attack()
```

## Учебные псевдо-сервисы

В старших секторах используются специальные учебные функции. Они не обращаются к настоящему интернету, файлам, базе данных или внешним пакетам. Это безопасные игровые имитации, которые возвращают маршрут или данные для текущего сектора.

Примеры:

```python
route = json.load("sector_29.json")
token = api.get("/auth")
route = api.get("/sector/30/route")
sql = "SELECT direction FROM route_34 ORDER BY step"
route = db.query(sql)
```

Также используются:

```python
file.read_lines("sector_15.txt")
module.load_route("sector_14")
data.load("dataset_22")
generate_route("sector_17")
controller.plan("sector_18")
algorithm.shortest_path("sector_20")
automation.plan("sector_31")
package.load("pyquest.routing")
async.fetch("sector_33")
debug.log("текст")
test.assert_goal("collect_all")
```

Эти функции нужны для учебной привязки механики к теме уровня. Например, JSON-сектор работает через `json.load(...)`, API-сектор через `api.get(...)`, а SQLite-сектор через `db.query(...)`.

## Запуск проекта

1. Установить **Godot 4.x**.
2. Распаковать архив проекта.
3. Открыть Godot.
4. Нажать **Import**.
5. Выбрать файл:

```text
project.godot
```

6. Открыть проект.
7. Нажать **Play**.

Главная сцена проекта запускает главное меню PyQuest. Основной режим открывается через карту кампании.

## Экспорт в Windows EXE

Чтобы собрать игру в `.exe`:

1. Открыть проект в Godot.
2. Перейти в меню:

```text
Project -> Export...
```

3. Если шаблоны экспорта не установлены, установить их через:

```text
Editor -> Manage Export Templates...
```

4. В окне экспорта нажать **Add...**.
5. Выбрать **Windows Desktop**.
6. Указать путь, например:

```text
build/PyQuest.exe
```

7. Нажать **Export Project**.
8. Для финальной версии не включать `Export With Debug`.

Если Godot создаст рядом файл `.pck`, его нужно хранить рядом с `.exe`:

```text
PyQuest_Windows/
 ├── PyQuest.exe
 └── PyQuest.pck
```

- симуляция игрового мира;

Главный модуль режима:

Он отвечает за:

- загрузку уровней;

- разбор учебного кода;
- выполнение команд героя;

Переиспользуемые элементы интерфейса:

Данные кампании:

- эталонное решение;
- подсказки;

## Ограничения проекта

- Игра использует учебный симулятор, а не настоящий внешний Python-интерпретатор.
- Псевдо-сервисы `api`, `db`, `json`, `file`, `module`, `package`, `async` работают внутри игры и не обращаются к реальным внешним системам.
- Проверка кода рассчитана на учебные сценарии и темы секторов.
- Проект не заменяет полноценную практику в IDE, но помогает изучить основы алгоритмического мышления и синтаксиса Python через игровое прохождение.
