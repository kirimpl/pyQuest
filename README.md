## Краткое описание

**PyQuest** обучает Python через короткие уроки и практические задания. Пользователь начинает с базовых тем вроде `print()`, переменных, типов данных и условий, а затем переходит к более практическим разделам: файлам, исключениям, ООП, JSON, CSV, API, регулярным выражениям, тестированию, логированию, типизации, `dataclass`, `async/await`, SQLite и финальному мини-проекту.

Игра не запускает настоящий Python-код внутри приложения. Вместо этого используется безопасная имитация интерпретатора: введённый пользователем код проверяется по заранее заданным правилам, допустимым вариантам и типичным ошибкам. Такой подход подходит для учебной игры, потому что исключает выполнение произвольного кода и сохраняет контроль над заданиями.

## Типы заданий

В проекте используется несколько типов заданий.

### `single_choice`

Выбор одного правильного ответа из нескольких вариантов.

Пример:

```text
Какая команда выводит текст на экран в Python?

1. print("Hello")
2. echo("Hello")
3. console.log("Hello")
4. show("Hello")
```

### `fill_blank`

Заполнение пропуска в коде или выражении.

Пример:

```python
____("Python")
```

Ответ:

```python
print
```

### `find_error`

Поиск ошибки в предложенном фрагменте кода.

Пример:

```python
console.log("Hello")
```

Правильный ответ: используется команда из JavaScript, а в Python нужен `print()`.

### `code_order`

Сборка программы из блоков кода в правильном порядке.

### `code_input`

Ввод кода в учебном окне интерпретатора. Пользователь пишет код, нажимает `Run`, после чего игра проверяет решение и показывает результат.

## Запуск проекта

1. Установить **Godot 4.6 Stable**.
2. Распаковать архив проекта.
3. Открыть Godot.
4. Нажать **Import**.
5. Выбрать файл:

```text
project.godot
```

6. Открыть проект.
7. Нажать **Play**.

Главная сцена проекта указана в настройках Godot и запускает главное меню PyQuest.

## Экспорт в Windows EXE

Чтобы собрать игру в `.exe`:

1. Открыть проект в Godot.
2. Перейти в меню:

```text
Project -> Export...
```

3. Если шаблоны экспорта не установлены, установить их через:

```text
Editor -> Manage Export Templates...
```

4. В окне экспорта нажать **Add...**.
5. Выбрать **Windows Desktop**.
6. Указать путь, например:

```text
build/PyQuest.exe
```

7. Нажать **Export Project**.
8. Для финальной версии не включать `Export With Debug`.

Если Godot создаст рядом файл `.pck`, его нужно хранить рядом с `.exe`:

```text
PyQuest_Windows/
 ├── PyQuest.exe
 └── PyQuest.pck
```

## Сохранение прогресса

Прогресс сохраняется через `SaveManager` в файл:

```text
user://pyquest_progress.json
```

Сохраняются:

- выбранный уровень;
- текущий индекс задания;
- максимальный открытый уровень;
- количество очков;
- количество ошибок;
- список пройденных уровней;
- список выполненных заданий;
- состояние музыки;
- состояние звуков;
- громкость музыки;
- громкость звуков.

В настройках есть кнопка сброса прогресса.

## Настройки звука

В игре реализованы:

- включение и выключение музыки;
- включение и выключение звуков;
- ползунок громкости музыки;
- ползунок громкости звуков.

Фоновая музыка хранится в папке:

```text
assets/audio/music/
```

Используется случайное воспроизведение треков. После завершения одного трека автоматически выбирается следующий случайный трек.

Звуки интерфейса находятся в папке:

```text
assets/audio/sfx/
```

## Как устроен контент

Контент вынесен в JSON-файлы, чтобы уроки и задания можно было редактировать без изменения сцен.

### `data/lessons.json`

Каждый урок содержит:

```json
{
  "level": 1,
  "title": "Введение в Python",
  "description": "Первый запуск кода и функция print().",
  "console_title": "Python 3.12 - первый пример",
  "icon": "res://assets/icons/levels/01_intro_small.png",
  "objectives": [
    "понять, как Python выполняет код сверху вниз"
  ],
  "text": "Текст урока...",
  "code": "print(\"Hello, PyQuest!\")",
  "example_output": "Hello, PyQuest!"
}
```

### `data/tasks.json`

Каждое задание содержит:

```json
{
  "id": 101,
  "level": 1,
  "order": 1,
  "type": "single_choice",
  "question": "Какая команда выводит текст на экран в Python?",
  "answers": [
    "print(\"Hello\")",
    "echo(\"Hello\")"
  ],
  "correct": 0,
  "score": 10,
  "explanation": "Для вывода данных в Python используется print().",
  "hint": "Вспомни первую команду урока."
}
```

Проверка заданий выполняется в `task_evaluator.gd`.

## Архитектурные решения

Проект разделён на несколько слоёв.

### `scripts/core`

Общая логика проекта:

- состояние игры;
- сохранение и загрузка;
- маршрутизация сцен;
- загрузка контента;
- проверка заданий;
- музыка и звуки.

### `scripts/ui`

Контроллеры экранов. Они не создают интерфейс с нуля, а управляют уже собранными `.tscn`-сценами.

### `scripts/components`

Переиспользуемые UI-компоненты:

- карточка уровня;
- вариант ответа;
- блок кода;
- окно учебного интерпретатора;
- анимированный фон;
- элемент справочника.

### `data`

Учебный контент: теория и задания.

### `theme`

Единая тема интерфейса. Она используется для общего визуального стиля кнопок, панелей, текста и элементов управления.

## Проверка кода

В заданиях с вводом кода используется не настоящий интерпретатор Python, а имитация проверки.

Проверяются:

- совпадение с допустимыми вариантами решения;
- лишние пробелы;
- одинарные и двойные кавычки;
- точка с запятой вне строк;
- незакрытые строки;
- отсутствие `:` после `if`, `for`, `while`, `def`, `else`, `elif`, `with`, `try`, `except`;
- отсутствие отступа после блочных конструкций;
- `print` без скобок;
- некоторые типичные ошибки по конкретным заданиям.

Это сделано для безопасности и предсказуемости учебного процесса.

## Ограничения проекта

- Игра не выполняет настоящий Python-код.
- Проверка кода работает по учебным правилам и допустимым вариантам.
- Проект не заменяет полноценную практику программирования в реальной IDE.
- Для глубокого изучения Python после прохождения игры рекомендуется писать самостоятельные проекты.

При этом PyQuest подходит как учебный тренажёр для начального и среднего уровня, потому что даёт последовательную программу, практику и разбор типичных ошибок.
